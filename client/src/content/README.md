# 📝 Website Content & Text Editor Guide

Welcome! This folder contains all the user-facing text, headlines, descriptions, button labels, and FAQ items on the website.

**You do NOT need programming knowledge to edit these files.** Just open any file below in your text editor and change the text inside the quotation marks `'...'`.

---

## 📂 Quick Content Map

| File | What you can edit in this file |
| :--- | :--- |
| **[`homeContent.ts`](./homeContent.ts)** | Homepage headline, banner subtitles, feature cards, and section titles. |
| **[`aboutContent.ts`](./aboutContent.ts)** | Mission statement, problem & solution overview, project roadmap steps, and technology stack descriptions. |
| **[`helpContent.ts`](./helpContent.ts)** | Wayfinding guide, step-by-step help, and all Frequently Asked Questions (FAQs). |
| **[`locationsContent.ts`](./locationsContent.ts)** | Directory title, search placeholders, filter categories, expand/collapse button labels, and empty state messages. |
| **[`exploreContent.ts`](./exploreContent.ts)** | Navigation planner headers, start/destination input placeholders, and map legends. |
| **[`authContent.ts`](./authContent.ts)** | Login & registration titles, campus precautions checklist, password criteria guidelines, and demo credentials notice. |
| **[`footerContent.ts`](./footerContent.ts)** | Footer branding description, office address, contact email/phone, and copyright notice. |

---

## 💡 How to Edit Text
1. Open the file you want to change (e.g. `homeContent.ts`).
2. Locate the text you wish to modify. Example:
   ```ts
   // BEFORE:
   titleLine1: 'Find Your Way',

   // AFTER:
   titleLine1: 'Navigate Campus',
   ```
3. Save the file (`Ctrl + S` or `Cmd + S`).
4. The website will automatically update in your browser!

> ⚠️ **Tip:** Make sure to keep the single quotes `'...'` around your text and the commas `,` at the end of each line.
